1. Autoestudos da semana (Adalove)

Semana 01, que cobre os encontros de 04/08 (Aula 01) e 07/08 (Aula 02). Os que se aplicam a esta aula, na ordem em que o roteiro os usa:

  1. Instalação do Python e Jupyter Notebooks em VS Code Pressuposto do daily: o ambiente precisa estar rodando em cada máquina antes do primeiro bloco.
  2. Migrando do Javascript para o Python Base da comparação entre objeto Javascript e dicionário Python, no bloco de 10h30 às 10h45.
  3. Listas, Tuplas, Conjuntos e Dicionários em Python As quatro estruturas usadas para agrupar o abate por período e para conferir a unidade da série.
  4. Aprendendo a ler erros em Python Base do bloco de 11h00 às 11h30, em que os erros são provocados de propósito sobre o CSV do IBGE.
  5. Melhor forma de aprender Python (Google Colab Notebook) O laboratório da aula roda no Colab pelo badge do próprio notebook.
  6. Opcional: Listas e Tuplas - o que são e como usar estes Tipos Agregados em Python Reforço opcional da diferença entre lista e tupla, que a aula usa mas não esgota.

Os quatro primeiros são os que o roteiro da Aula 01 cita nominalmente. Os demais autoestudos da Semana 01 na Adalove (qualidade dos dados, tipos de dados, taxonomia, introdução a Machine Learning e IA) são pressupostos da Aula 02, em 07/08, e aparecem na página de referências dela.

Estes títulos são cópia literal de docs/autoestudos-por-semana.md, que é gerado do Turma.xlsx oficial. Autoestudo que não está lá não entra aqui. O acesso ao conteúdo é pela Adalove, com o login institucional.

2. Leitura complementar do professor

A curadoria definitiva desta seção ainda será fechada pelo professor. Até lá, ficam aqui as fontes efetivamente citadas no deck e no material de apoio desta aula, na mesma numeração usada no slide de referências:

  1. IBGE. Pesquisa Trimestral do Abate de Animais, tabela 1092 do SIDRA. A origem do arquivo da aula. Vale abrir para ver que a própria interface do IBGE só oferece trimestre, o que confirma o reparo feito em sala. A série usada está versionada em dados/abate_bovinos.csv, com o contrato de colunas em dados/README.md.
  2. Python Software Foundation. Biblioteca padrão, módulo csv. A diferença entre csv.reader (que devolve lista, indexada por posição) e csv.DictReader (que devolve dicionário, indexado por chave) é a origem dos dois erros provocados na aula.
  3. Python Software Foundation. Tutorial, estruturas de dados. Lista, tupla, conjunto e dicionário no texto oficial, com os métodos que a aula usa: get, keys e as compreensões.
  4. Python Software Foundation. Tutorial, erros e exceções. A anatomia do traceback e a hierarquia das exceções. Ler a seção de exceções antes da Aula 09, quando o tratamento de erro deixa de ser diagnóstico e passa a ser parte do pipeline.
