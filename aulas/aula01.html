Tudo que sai de um CSV é texto

Lista, tupla, conjunto

Lista

[782228696.0, ...]

Ordenada e mutável: os 117 valores na ordem do arquivo.

Tupla

("2025-T4", 2937449898.0)

Ordenada e imutável: um registro que não deve ser alterado.

Conjunto

{"Quilogramas"}

Sem ordem e sem repetição: responde "quantas unidades diferentes existem?".

Aplicado ao arquivo: o conjunto das unidades tem tamanho 1, então a série inteira está na mesma unidade e pode ser somada sem conversão [3].

O dicionário é o objeto que você já conhece

// Javascript
const registro = {
  periodo: "2025-T4",
  valor: 2937449898.0
};
registro.periodo;
Object.keys(registro);
# Python
registro = {
    "periodo": "2025-T4",
    "valor": 2937449898.0,
}
registro["periodo"]
registro.keys()

Mesma ideia de chave e valor, três diferenças que pegam quem vem do Javascript: a chave é escrita entre colchetes e aspas, não com ponto; a chave é um objeto Python qualquer, não só texto; e chave ausente levanta erro em vez de devolver undefined. Essa terceira diferença volta em 20 minutos.

Ler o arquivo

10h45 · 11h00 · prática guiada em duplas

Quinze linhas resolvem o arquivo inteiro

import csv

with open("dados/abate_bovinos.csv") as arquivo:
    leitor = csv.reader(arquivo)
    cabecalho = next(leitor)
    linhas = list(leitor)

cabecalho
# ['periodo', 'valor', 'unidade']

len(linhas)
# 117

linhas[0]
# ['1997-T1', '782228696.0', 'Quilogramas']

with fecha o arquivo mesmo se o código falhar no meio [2].

next() consome a primeira linha, que é o cabeçalho, e deixa o leitor posicionado no primeiro registro de dado.

Cada linha vem como lista de textos. Nada de número ainda.

Ler o traceback

11h00 · 11h30 · o erro é a mensagem, não o fracasso

IndexError: pedi a quarta de três colunas

for linha in leitor:
    print(linha[3])

Traceback (most recent call last):
  File "leitura.py", line 6, in <module>
    print(linha[3])
          ~~~~~^^^
IndexError: list index out of range

Leia de baixo para cima [4]. A última linha diz o tipo e a causa. As de cima dizem onde.

linha tem três posições: 0, 1 e 2. A posição 3 é a quarta, e ela não existe.

Pergunta: qual índice devolve a unidade?

Módulo 03 IN · Aula 01 · Sprint 1

15

KeyError: pedi um mês a um arquivo trimestral

for linha in csv.DictReader(arquivo):
    print(linha["mes"])

Traceback (most recent call last):
  File "leitura.py", line 4, in <module>
    print(linha["mes"])
          ~~~~~^^^^^^^
KeyError: 'mes'

O KeyError traz a chave pedida entre aspas: 'mes'. Ele não diz que a chave está errada, diz que ela não está lá.

Em Javascript isso devolveria undefined e o erro apareceria muito depois, longe da causa. Python interrompe no lugar do problema.

E o arquivo não tem mês porque não tem: guardem isso.
