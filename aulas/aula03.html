Bloco 2 · Numpy

10h45 · 11h15 · vetorização e localização de picos

Uma linha em vez de um laço

import numpy as np

valores = df["valor"].to_numpy()

variacao = (
    np.diff(valores) / valores[:-1]
) * 100

idx = np.argmax(np.abs(variacao))
periodos = df["periodo"].to_numpy()
print(periodos[idx], "->", periodos[idx + 1])
print("%.2f%%" % variacao[idx])

np.diff [3] devolve a diferença entre cada trimestre e o anterior, de uma vez, sem laço em Python. Dividindo pelo valor anterior, vira variação percentual.

Rodado sobre abate_bovinos: o maior salto da série inteira é +14,65%, de 2005-T1 para 2005-T2.

Com periodo no eixo x [4], a tendência de crescimento aparece de imediato, e o salto encontrado no Bloco 2 vira um ponto fora da curva. Atenção: o eixo x do lineplot é categórico, então xy usa a posição i, não o texto do período. ROXO e CORAL vêm das duas constantes de cor do tema, definidas uma vez, não de hex solto no código.

Sazonalidade: nem toda série é igual

Agrupando producao_leite por trimestre do ano e tirando a média de cada grupo, aparece um padrão real: T2 é sempre o mais baixo, T4 o mais alto.

df["trimestre"] = df["periodo"].str[-2:]
sazonal = (df.groupby("trimestre")["valor"]
             .mean().reset_index())

sns.barplot(data=sazonal, x="trimestre",
            y="valor", hue="trimestre",
            palette=[ROXO] * 4, legend=False)

É um padrão, não uma causa: o material de apoio traz uma hipótese, sem confirmá-la com este dado. (O gráfico ao lado destaca T2 e T4 em cores diferentes só para leitura mais rápida; o código acima, mais simples, pinta as quatro barras da mesma cor.)

O resultado que ninguém espera: zero

for nome, df in series.items():
    n = df["valor"].isna().sum()
    print(nome, n, "vazios")

# abate_bovinos    0 vazios
# abate_suinos     0 vazios
# abate_frangos    0 vazios
# producao_ovos    0 vazios
# producao_leite   0 vazios

As cinco séries têm zero valores ausentes. Não é porque o IBGE nunca suprime dado: é porque tools/baixar_dados.py já filtrou os marcadores de ausência ("...", "-", "X", "*") antes de gravar o CSV.

Nota (2 min). isna() só diagnostica: conta célula vazia. fillna() e dropna() agem: preenchem ou descartam. A escolha entre as duas depende do que o dado significa, não de qual é mais fácil de chamar; aqui deu zero porque o filtro já rodou antes, em base crua isso não acontece. O aprofundamento dessa escolha é da Aula 04.
